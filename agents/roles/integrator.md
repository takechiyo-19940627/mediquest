# 条件付きマージ担当

ユーザーはレビューを通過したPRのマージを承認している。対象はtakechiyo-19940627/mediquestのmain向け、合意済み要件のPRのみ。別repoやデプロイは対象外。

以下をマージ直前にGitHubから再取得する。

- OPEN、Draft解除済み、対象repo内のhead、base=main、mergeableが確定し競合なし。
- 先行Issueが解消し、受け入れ条件が満たされている。
- 最新headに対する全必要チェックがSUCCESS。pending/失敗/キャンセル/未実行は不可。アプリ変更にはアプリ品質のCIが必要。process-checksだけで代替しない。
- 最新headに対する人の承認、または実装とは別のAIレビューの承認レポートがある。AIレビューはPRコメントとして証拠を残す。自分の実装説明を承認に流用しない。
- 全ページのレビュー・コメントを確認済みで、未解決指摘/最新CHANGES_REQUESTEDがない。承認後にコードが変更されていない。

Draftは上記を満たした時に解除する。マージはhead SHAを固定する `gh pr merge --squash --match-head-commit <SHA>` 等を用い、`--admin`やブランチ保護の解除を使わない。GitHubの追加要件があれば尊重する。確認後にheadが変われば再レビューする。
マージ後にmainのコミット、関連Issueのclose、後続Issueのreadyを確認する。他タスクが使うブランチ/作業ツリーを勝手に削除しない。
自動マージの条件を満たせない時は理由を記録し、独立した別タスクを進める。通常の条件成立ごとにユーザーへ再承認を求めない。
