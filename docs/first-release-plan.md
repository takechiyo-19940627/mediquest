## 初回で維持する契約

- 演習は公開セットの採用順を開始時に保存する。復習は元演習の対象版と相対順を保持する。開始時のランダム化は導入しない（#28/#44）。
- 選択肢は2〜6件、必要選択数はサーバーが指定する可変数。1つ・2つ・3つ以上とも「選択→回答する」で確定し、回答前に正解IDを渡さない（#18/#30/#48）。
- 生成は同じ入力・受付キーで状態を確認し、明示的な新しい生成だけ新キーを使う。残存runningを生存保証や確定失敗として扱わず、更新時刻と追加試行の意味を伝える（#20）。自動再課金する復旧は導入しない。
- 不備確定と通常改訂を区別し、過去の版・解答を保持する。不備は集計から除外し、対象0件を0%と表示しない。

画像OCR、外部認証・外部提供、リモート配備、ネイティブアプリ、オフライン同期、複数AI事業者、永続生成worker/自動復旧、AI正解再判定、全体・教材別の横断成績集計は初回対象外。演習単位の結果・履歴は対象内である。旧Rust要求の機能を無条件に初回Web版へ追加しない。

統合受入で検出したコントラスト不具合は [#85](https://github.com/takechiyo-19940627/mediquest/issues/85) で追跡し、修正後のaxe検査・目視・全ゲートを最終確認する。
